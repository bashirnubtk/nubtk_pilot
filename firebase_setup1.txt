======================================================
NEW LAPTOP FIREBASE & NODE SETUP COMMANDS
======================================================

১. Node.js এবং NPM ভার্সন চেক:
   কমান্ড: node -v
সমস্যার সমাধান (PowerShell Error Fix)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

   কমান্ড: npm -v

২. ফায়ারবেস টুলস ইনস্টল করা (একবারই করতে হবে):
   কমান্ড: npm install -g firebase-tools

৩. ফায়ারবেসে লগইন করা:
   কমান্ড: firebase login

৪. প্রজেক্টের লাইব্রেরি বা ডিপেন্ডেন্সি ঠিক করা:
   (নতুন ল্যাপটপে কোড নামানোর পর এটি অবশ্যই করতে হবে)
   কমান্ড: cd functions
   কমান্ড: npm install
   কমান্ড: cd ..

৫. ক্লাউড ফাংশন ডিপ্লয় করার কমান্ড:
   কমান্ড: firebase deploy --only functions

৬. ফ্ল্যাটার প্যাকেজ আপডেট করা:
   কমান্ড: flutter pub get

======================================================
NEW LAPTOP SETUP - FIREBASE & AI CONFIGURATION
======================================================

১. পাওয়ারশেল এরর সমাধান (টার্মিনালে লাল কালি আসলে আগে এটি করুন):
   কমান্ড: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   (এরপর 'Y' লিখে এন্টার দিন)

২. ফায়ারবেস লগইন:
   কমান্ড: firebase login

৩. AI লাইব্রেরি এবং ডিপেন্ডেন্সি ইনস্টল (সবচেয়ে গুরুত্বপূর্ণ):
   প্রজেক্টের রুট ফোল্ডার থেকে এই কমান্ডগুলো দিন:
   কমান্ড: cd functions
   কমান্ড: npm install
   কমান্ড: npm install @google/generative-ai
   কমান্ড: cd ..

৪. Gemini API Key সেটআপ:
   - Google AI Studio থেকে কী (Key) সংগ্রহ করুন।
   - কমান্ড: firebase functions:config:set gemini.key="আপনার_এপিআই_কী"

৫. লোকাল কনফিগ তৈরি (ডেভেলপমেন্টের জন্য):
   কমান্ড: cd functions
   কমান্ড: firebase functions:config:get > .runtimeconfig.json
   কমান্ড: cd ..

৬. ক্লাউড ফাংশন ডিপ্লয়:
   কমান্ড: firebase deploy --only functions

৭. ফ্লাটার প্রজেক্ট রান:
   কমান্ড: flutter pub get
   কমান্ড: flutter run
