======================================================
NEW LAPTOP FIREBASE & NODE SETUP COMMANDS
======================================================

১. Node.js এবং NPM ভার্সন চেক:
   কমান্ড: node -v
   কমান্ড: npm -v

২. ফায়ারবেস টুলস ইনস্টল করা (একবারই করতে হবে):
   কমান্ড: npm install -g firebase-tools

৩. ফায়ারবেসে লগইন করা:
   কমান্ড: firebase login

৪. প্রজেক্টের লাইব্রেরি বা ডিপেন্ডেন্সি ঠিক করা:
   (নতুন ল্যাপটপে কোড নামানোর পর এটি অবশ্যই করতে হবে)
   কমান্ড: cd functions
   কমান্ড: npm install
   কমান্ড: cd ..

৫. ক্লাউড ফাংশন ডিপ্লয় করার কমান্ড:
   কমান্ড: firebase deploy --only functions

৬. ফ্ল্যাটার প্যাকেজ আপডেট করা:
   কমান্ড: flutter pub get
======================================================
